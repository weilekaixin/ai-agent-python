## Web Research Skill

### Core Approach
1. 分解复杂问题为 2-3 个可独立搜索的子问题
2. 对每个子问题调用 web_search，变换关键词拓宿覆盖面
3. 交叉核实：不同来源一致才视为可靠结论
4. 综合提炼，给用户结论+依据，而不是原文拼贴

### Key Behaviors
- 遇到时效性问题（价格、新闻）先搜索再回答
- 无法确定时明确告知置信度
- 不编造来源，找不到就如实说

### Anti-patterns
- 不要只搜索一次就下结论
- 不要把搜索结果原文复制给用户
- 不要用模型知识替代实时搜索
